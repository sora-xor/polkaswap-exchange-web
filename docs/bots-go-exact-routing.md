# New GO goals and exact v1 resumes

The simple GO action always starts fresh AI research for the user's exact input budget, output token, fee reserve, target and drawdown limit. A 10 KUSD → XOR input with a 1 XOR reserve and 5%/5% limits no longer selects a previously shipped exact v1 certificate. The research goal requires a finalized fill and a portfolio value above the unchanged opening allocation after fees before it can report a target. Research and review remain unsigned; Start still requires the user's wallet approval.

Existing exact v1 bots retain their original ledger, qualification digest and fixed policy. Resume recognizes the saved exact execution marker and obtains a new release-backed review. It does not change the old goal's accounting or silently migrate it to a different strategy. Exact v1's `target` means its original +5% opening-value threshold; that threshold can be reached from a passive KUSD/XOR mark without a trade, so it is not evidence of AI outperformance. Its display calls this a **value threshold** and notes when the goal's last marked holdings did not beat leaving the opening allocation untouched after fees. If a later settlement changes holdings without a new mark, the note is hidden because the old comparison no longer describes those holdings. This display calculation never changes the persisted outcome or claims a gain at the earlier stop time. A future exact protocol would need a new version, separately replayed qualification and release certificate rather than an in-place change to v1.
