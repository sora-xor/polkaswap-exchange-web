Network Statistics uses verified archive days when regular calendar or block data cannot establish transaction or bridge counts. The selected indexer must return fresh recovery capabilities and exact coverage for each UTC interval. The page does not add overlapping observations or count missing days as zero. Activity and new accounts still require separate evidence. The reader neither infers distinct accounts from a paid-transaction count nor changes volume, fees or reward balances.

When an entire range cannot be totaled, expand **Verified archive days** to see the complete UTC dates covered within it. The table shows exact transaction and bridge counts for those dates. Dates cut off by either end of the selected range are excluded from the table but may still contribute to a fully verified total.

The mainnet download contains independently verified historical UTC dates. Empty CSV fields represent unavailable values, while a numeric zero represents verified zero activity. The priced swap subtotal includes only swaps with verified prices on both sides. If any successful swap lacks a price, the full-day USD volume stays blank. Counts of distinct accounts must not be added across dates. The download is a dated file included in the static site.
