# Buy XOR payment review

- Visual thesis: retain Polkaswap's calm neumorphic surfaces, compact typography and existing action color, with one dominant checkout action.
- Content plan: show the USD card charge and estimated net XOR first, then ETH reserved for conversion/bridge fees; keep technical detail in the existing disclosure pattern and place the provider action after readiness.
- Interaction thesis: use the existing short button/pressed transitions, announce loading and stale estimates in place, and preserve stable layout as refreshed amounts arrive. Respect reduced-motion settings; add no decorative animation to a financial review.

The card review appears after the receiving accounts are selected. Its result must bind the current amount, accounts, network and short-lived fee/quote evidence. Unknown costs revoke checkout readiness. An estimated reserve is labeled as such; the provider and eventual signing reviews remain authoritative.

General purchase measurement has a separate optional preference below the main task. It must not interrupt a purchase, include financial identifiers, or imply that aggregate event counts identify individual customers.
