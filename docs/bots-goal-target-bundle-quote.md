# V3 quote artifact replay

`scripts/bots/goal-target-bundle-quote.ts` exports the fixed Node-only `verifyGoalTargetBundleQuote(binding, bytes, options)`. It performs no network requests and accepts no injected verifier, worker path, or host implementation. It returns `{ result, counts }`: the original `GoalEpisodeQuoteResult` projection and the number/UTF-8 size of the original physical target RPC responses.

The binding contains the existing quote identity, pending input, causal clock, cutoff and fee policy; the exact execution model and directional maximum input lots; and an owned `GoalBundleVerifiedMarketState`. Obtain that capability from `getGoalBundleVerifiedMarketState(actualVerifiedMark)` after the browser-compatible original market verifier has checked the schema, canonical block and seven-key storage batch. A copied mark or capability is rejected. The frozen capability retains the original source block, mark, finalized-source identity, genesis, denomination, runtime, metadata, Properties, raw-state digest, request and source-manifest identities. Existing V2 mark return fields are unchanged.

Supply the original quote and context wrapper bytes, the fee wrapper only for successful estimates, and all individually pinned `target-rpc-<checkId>-<id>.json` wrapper bytes with their original canonical value digests. The upstream pinned bundle reader remains responsible for exact wrapper **file-byte** hashes; this verifier independently checks canonical wrapper encoding, logical name, request and canonical **value** digest. Every RPC must appear exactly once, in the original contiguous sequence, and must equal its corresponding receipt embedded in the quote. The actual source Properties receipt must also equal the separately authenticated market-state value. Cached valuation reserves are not substituted for runtime account balances.

The wrapper encoding sorts object keys. The target state codec originally hashes `JSON.stringify` of transport receipts in its fixed field order. Replay reconstructs precisely those nine original success-envelope fields in the original transport order before re-execution; raw request/response strings, acquisition timestamps, values and array order stay unchanged. Whole-result comparison still includes the original receipt digest and all worker API traces. Canonical reserialization cannot manufacture matching authority flags.

Before worker execution, the verifier checks the compressed binary pin and hashes the three fixed local host/state-codec/quote-codec files against the declared model implementation pins. The explicit catalog model additionally pins the actual `runtime-catalog.ts` implementation bytes. It then invokes the actual `replayGoalTargetRuntimeEstimate` helper, which re-verifies all original storage claims and executes the pinned target131 worker. The original model keeps historical source130 provenance separate from target131 hypothetical execution. Complete state, raw APIs, envelope, fee details, flags and success/unavailability must match the retained estimate.

Successful fee artifacts must exactly reproduce the replayed fees, bounded envelope and two fee API receipts. Genuine unavailable routes require the absence of a fee artifact and return no fabricated fee/output. Genuine fees above the declared cap and high-impact quotes remain raw evidence for the unchanged episode evaluator to reject; this join neither changes economic gates nor grants qualification.

The caller's bytes and plain data are detached before the first await. A single monotonic timeout of at most 30 seconds covers preparation and worker replay; abort propagates to the terminable worker, and no result returns after cancellation or timeout. Per-quote original transport limits are 269 requests, 256 KiB per response and 8 MiB aggregate response bytes. The episode source must add returned counts once to its full episode limits; it must not count both embedded receipts and their separate retained wrappers.

Tests use invented storage and original-style wrappers, the real market codec, public pinned metadata and the exact installed runtime binary. They cover both trade directions, unavailable routes, ownership, source/model/Properties/fee/context joins, malformed and duplicate RPC artifacts, hash resealing, preserved acquisition timestamps, caller mutation, accessors, cancellation and deadlines. No actual study or market data is opened.

## Finite catalog model

The same entrypoint explicitly dispatches `source128-129-130-target131-readonly-counterfactual-v1` to `replayGoalCatalogTargetRuntimeEstimate`. It retrieves the privately owned catalog through `getGoalBundleVerifiedMarketCatalog(sourceState)`; a serialized catalog, copied state, legacy state, or catalog state paired with the legacy model cannot substitute for this capability. The exact source profile must belong to the model's fixed three-profile set. The source block, full catalog block/profile association, qualification profile, source metadata bytes, catalog digest and profile digest must agree. Catalog profile digests include genesis; qualification profiles retain their original four fields.

Properties keys are derived by the actual selected catalog pool codec, and the retained target-state Properties receipt must equal the separately verified same-block market value. Catalog target replay reconstructs the original `sourceBindingSha256` from the genuine retained state receipts and compares the entire saved estimate, including actual source runtime, catalog and state binding, raw quote and fee APIs. It never substitutes source130 for source128/129, nor substitutes cached mark reserves for target API account balances. Source capability liveness is checked both before and after the worker await, so metadata cancellation or validation-selection revocation cannot produce a returned quote. No additional fee or economic acceptance is inferred.

Focused catalog tests construct an actual synthetic metadata collector result, browser metadata capability, original catalog market reader receipts and owned market state, then execute the pinned target131 worker for all three source runtimes. They include both directions, unavailable routes, wrong supported profile, changed catalog/state binding, altered original receipt, mismatched Properties, copied or legacy state, changed decoder pin and cancellation of the source capability during worker replay. Values are invented; public retained schema and target binary bytes are the only external artifacts read.
