# Size-specific costs before AI drafting

20 September 2026. GO previously gave the model one cost observation for a small reference amount and told it to re-quote other sizes. The one-shot drafting interfaces did not expose a quote operation. Exact quotes obtained after the draft protected execution but could not inform that draft's sizing decision.

The revised flow collects a bounded table before calling the model: the existing partial reference, one quarter of spendable input, and one half. Exact base-unit arithmetic removes zero, duplicate and whole-budget amounts. For 10 KUSD this normally supplies 1, 2.5 and 5 KUSD cost probes; these are observations, not orders or a selected allocation. No extra user setup is required.

Each available point carries its amount, finalized block/time, and separate buy/sell network fees, pool fees and impact. The original cost object remains exactly tied to the reference amount. A generic loader quote rejection becomes an unavailable point with no numeric costs; that category may include a timeout or normalization failure and does not prove absent liquidity. Returned malformed evidence, stale observations, identity mismatches, cancellation and other errors still stop setup. Available points are rechecked before drafting.

The common validator preserves the same bounded data across API providers, Jev and native/portable desktop contexts. It rejects untrusted accessors, sparse arrays, duplicate amounts, budget violations and a reference point that differs from the original cost object. The prompt explains that the app checks exact candidate sizes after drafting and re-quotes before live execution. It does not imply a tool the model cannot use or allow interpolation of unsampled costs.

The candidate search, original funding, XOR reserve, impact ceiling, loss limit and untouched validation remain unchanged. A prior cost point is reused only for the same exact amount and cadence while fresh. This fixes a missing model input; it does not lower chain fees, qualify a strategy or establish profitability. No transaction or successful-trade recording is claimed.
