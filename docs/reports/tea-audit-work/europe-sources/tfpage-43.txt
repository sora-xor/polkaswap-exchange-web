Courrier électronique

Une adresse électronique est mise a votre disposition dés votre arrivée sur le district, par le bureau cen-
tral radio (BCR). Ces adresses sont nominatives et prennent le format suivant :

+ Pour CROZET: prénom.nom@cro-taaf.fr

+ Pour AMSTERDAM : prénom.nom@ams-taaf.fr

+ Pour KERGUELEN : prénom.nom@ker-taaf.fr

+ Pour TERRE ADELIE : prénom.nom@ta-taaf.fr

La taille de chaque boite aux lettres est limitée a 5 Go.

Satellitaire

Les antennes satellitaires de type basse orbite (Starlink, Oneweb, ..) ne sont pas autorisées sur les territoires
des TAAF pour les hivernants. Les missions scientifiques peuvent demander une autorisation au préfet,
administrateur supérieur, des TAAF pour un usage professionnel.

Internet

Internet est accessible sur les districts via une connexion satellite. La bande passante attribuée par dis-
trict est limitée. Elle est prioritairement dévolue & un usage professionnel et scientifique.

Chaque hivernant dispose personnellement pour le loisir d’une connexion internet limitée en donnée par
mois avec un accés illimité 8 WhatsApp en signant au préalable la charte internet.

Téléphonie

> Des districts vers la métropole
Vous avez la possibilité d’utiliser a titre onéreux les liaisons téléphoniques par le
réseau VSAT des TAAF.

Le tarif des communications téléphoniques et de transmission de fax, fixé par les
TAAF, au départ d'une ligne fixe est de:
+ 0,50 €/minute vers la France métropolitaine et les DOM
+ 1,00€/minute vers I’étranger

Un forfait téléphonique mensuel est offert pour chaque hivernant :

+ vers la métropole : 2h par mois *

+ vers|’étranger : 1h par mois *
