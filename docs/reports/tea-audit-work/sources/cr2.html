Consultar Requisitos de Importación

Estimado Usuario, mediante este servicio podrá conocer los Requisitos Fitosanitarios de un determinado producto de importación.

Para poder realizar la consulta, primero debe escoger algunos de los filtros que se muestran. Después, debe dar click en el botón Consultar.

En la lista de productos que concuerdan con las caracteristicas especificadas, deberá dar click en el link de Requisitos, para ver el listado de Requisitos asociados al Producto.

Esta consulta de requisitos fitosanitarios es oficial, sin embargo, no sustituye las indicaciones estipuladas en el formulario de requisitos fitosanitarios, y el que el usuario deba estar inscrito en el Registro de Importadores.
